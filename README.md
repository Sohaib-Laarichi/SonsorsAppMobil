# 📱 SensorApp – Application Android de visualisation de capteurs

**SensorApp** est une application Android moderne développée en Java qui permet de visualiser en temps réel les données des capteurs intégrés à un smartphone :

- 🌡️ Température ambiante
- 💧 Humidité relative
- 📍 Proximité
- 🧲 Champ magnétique
- 📊 Graphiques dynamiques avec MPAndroidChart
- 📂 Navigation Drawer pour explorer les modules

---



## 🛠️ Technologies utilisées

| Outil                | Description                          |
|---------------------|--------------------------------------|
| Java                | Langage principal                    |
| Android Studio      | IDE de développement                |
| MPAndroidChart      | Pour afficher les données en graphe |
| RecyclerView        | Liste dynamique des capteurs        |
| CardView            | UI moderne                          |
| Navigation Drawer   | Navigation entre fragments          |

---

## 🧪 Fonctionnalités

- Détection automatique des capteurs disponibles
- Interface utilisateur animée et intuitive
- Graphiques mis à jour en temps réel (ou simulés)
- Design responsive et compatible Android 8+
